# Icon assets

`assets/codex-cloud.png` and `assets/codex-cloud.ico` are an unofficial adaptation of the former Codex cloud-and-terminal icon. The dark tile was removed, the background made transparent, and the cloud enlarged for Windows shortcuts and taskbar use.

The image was adapted using ImageGen. It should not be presented as an official OpenAI release or used to imply endorsement.
